# Dream Travelers – Travel Agency Website

Dream Travelers is a travel agency website designed to help users explore beautiful destinations, discover travel packages, and plan their next getaway.

## Features

- **Login Page:** First page users see when accessing the website.
- **Home Page:** Attractive landing page with a travel-themed design.
- **Destinations:** Explore Indian and international destinations with interactive details.
- **Travel Packages:** Browse different travel packages and their information.
- **About Us:** Learn more about Dream Travelers.
- **Contact Us:** Contact section for travel enquiries.
- **Responsive Design:** User-friendly layout across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Pages

1. **Login:** First page users see when accessing the website.
2. **Home:** Main landing page.
3. **Destinations:** Explore travel destinations.
4. **Packages:** Discover holiday packages.
5. **About Us:** Learn about the travel agency.
6. **Contact Us:** Get in touch with the agency.

## Project Structure

- HTML files – Website pages
- travel.css – Website styling
- js/ – JavaScript files
- images/ – Website images

## Project Purpose

This project was developed to practise and improve frontend web development skills through the creation of a multi-page travel agency website.
